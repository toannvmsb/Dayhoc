    xúc bài G8/G9/HSG.

    `readiness`, `mastery`.
-   Tách Standard Curriculum khỏi Actual Taught Curriculum và
    Personalized Development Curriculum.

``` yaml

  skill_id: string
  curriculum_origin: G7_STANDARD|G8|G9|HSG
  knowledge_level: K0|K1|K2|K3|K4|K5
  thinking_level: T1|T2|T3|T4|T5

  readiness: not_ready|parallel_repair|ready
```

## Yêu cầu triển khai

1.  Normalize 37 bài SGK thành skill nguyên tử.
2.  Gán stable Skill ID.
3.  Xây Cross-grade Prerequisite DAG.
4.  Map Skill → Problem Type.
5.  Tách Skill Mastery khỏi Problem-Type Mastery.
6.  Tách Knowledge Level khỏi Thinking Level.
7.  Advanced/HSG chỉ mở khi Learning Readiness phù hợp.
8.  Hỗ trợ Parallel Gap Repair khi có prerequisite gap nhỏ.
9.  Homework/test/scan mới quyết định Actual Learning Frontier.
